MELODYWAVE — REACT VERSION

Run in VS Code:
1. Extract this ZIP.
2. Open the extracted MelodyWave_React folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm install
5. Run: npm run dev
6. Open the Local URL shown by Vite (usually http://localhost:5173).

IMPORTANT:
- Do not use Go Live for this React/Vite version. Go Live serves static HTML and does not run the Vite development server.
- Demo audio uses online sample MP3 URLs and requires internet access. These are not the actual commercial songs listed.
- Lyrics are sample placeholder text. Use a licensed lyrics provider or lyrics you have permission to display.
- This is a front-end demo. It does not include accounts, backend storage, real catalogue search or licensed streaming.
- Likes and created playlists are saved in this browser using localStorage.
